Los enlaces a repositorios y demostraciones se incorporarán

### Análisis de datos educativos con Excel

Proyecto formativo de preparación y análisis de información educativa.

- Limpié y normalicé datos, revisé duplicados y validé tipos de información.
- Construí relaciones entre tablas y elaboré **5 tablas dinámicas**
  con gráficos para explorar indicadores.
- Organicé un dashboard con indicadores y segmentadores.
- **Tecnologías:** Excel, Power Query y Power Pivot.


### Tablero de evaluación diagnóstica

Proyecto formativo de análisis de resultados educativos
de **7.º y 10.º de Educación General Básica**.

- Definí como indicador principal el porcentaje de estudiantes
  que alcanzan o superan el estándar.
- Trabajé con visualizaciones para explorar distribuciones,
  diferencias y posibles brechas de desempeño.
- Orienté el tablero a la identificación de hallazgos
  que apoyen decisiones educativas.
- **Tecnologías:** Power BI.


### Análisis de ventas de Comercial Andina

Proyecto formativo de análisis de ventas semanales por sucursal.

- Preparé resúmenes de ventas totales, promedio semanal,
  mínimos y máximos por sucursal.
- Organicé series temporales para comparar la evolución de ventas.
- Documenté hallazgos y su utilidad para la toma de decisiones.
- **Tecnologías:** Python, pandas y Google Colab.
